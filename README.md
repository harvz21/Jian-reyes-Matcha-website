# 🍵 Matcha Delight

Welcome to **Matcha Delight** — a modern, responsive website for a premium matcha brand. This project is designed to showcase elegant web design, basic form handling (Sign Up / Login), and clean navigation.

---

## 🌟 Features

- ✅ Responsive navigation bar
- ✅ Sign Up and Login pages with form validation
- ✅ Clean, minimalist design aesthetic
- ✅ Social login icons (placeholders)
- ✅ Smooth CSS animations and consistent styling
